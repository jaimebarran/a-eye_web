# 🌍 A-eye: Web Platform

This submodule contains the **web-based interface** for visualizing and exploring A-eye segmentation and morphometric results.

🚀 Live at **[aeye.hevs.ch](https://aeye.hevs.ch)**.

Features:

- Interactive 3D visualization of MR-Eye atlases  
- Quantitative morphometry dashboard  
- Segmentation result inspection and comparison  

---

Part of the **A-eye** project — automated 3D MRI segmentation and morphometric feature extraction for eye and orbit atlas construction, published in [*PLOS ONE*](https://doi.org/10.1371/journal.pone.0352257).

For the full project context, figures, and references, please see:  
👉 [A-eye main repository](https://github.com/jaimebarran/a-eye)
